The standard itself did not change

On April 20, 2026 the Department of Justice issued an interim final rule extending both Title II compliance dates by one year. Neither date has passed, and the Department has said it anticipates enforcing at the new ones. Documents published on a covered website are in scope alongside the pages that carry them.

What actually happens to a file

Every job returns the corrected document, the validator output for both versions, and a written note about the things a validator cannot judge.

Measure first

The published file is run through veraPDF against PDF/UA-1. You get the list of rules that failed, not an adjective.

Deterministic repair

Structure, language, headings, table scope, link text and document title are corrected. The same source file always produces the same output, and every change is listed.

Render check

Every page is raster-compared against the original at 100 dpi. When a report says pixel-identical, it means exactly that.

Human pass

Heading order, image descriptions and reading order need judgment. That work is done by a person, and whatever is left open is written down.

Translation quietly breaks accessibility

An accessible source PDF does not stay accessible through translation. The translated file usually comes out of the layout tool with no structure tree, and its language entry still declares the original language, so a screen reader pronounces Spanish text with English rules.

  • One Minnesota file declared a single language for the whole document, and two pages of the Spanish edition were still in English.
  • A bilingual Washington poster carried one language declaration and twenty-five links with no description.
  • Two published files already claimed PDF/UA conformance that the file itself could not support.
  • In one of them, a missing glyph was being used as a word space.

What this is not

The short version, so nobody finds out later.

A one-person practice

Throughput is roughly 500 pages a week at Tier 1, 250 at Tier 2, 100 at Tier 3. Large inventories get scheduled honestly or handed off.

Not assistive-technology testing

Files are validated with veraPDF and reviewed by a person. No claim is made about testing with screen readers, and no security certification is held.

No conformance claim it cannot back

The PDF/UA identifier is never written into a file until every other rule passes. A clean validator report is not the same thing as an accessible document, and the reports say so.
