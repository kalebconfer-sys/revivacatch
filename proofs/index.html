Proof of work · translated government documents

A tagged PDF does not stay tagged through translation. Four published files, measured before and after.

Each file below was published by a state agency as the Spanish or bilingual edition of a tagged document. Each was measured with veraPDF against PDF/UA-1, repaired, measured again, and raster-compared page by page against the original so nothing visible changed. Every report lists every rule that failed and exactly what was done, plus the defects a validator cannot see: wrong language declarations, untranslated pages, missing glyphs used as spaces, and conformance claims the file could not support.

How to read these

  • Before / after are veraPDF counts on the published file and on the remediated file, same profile, same version.
  • Rendering is a 100 dpi raster comparison of every page. "Pixel-identical" means exactly that.
  • Findings are the things a validator cannot judge. They are the reason a human pass exists, and the reason a clean validator report is not the same as an accessible document.
  • Each pass is deterministic: the same source file produces the same output, and every change is listed.
