Findings

A bilingual poster with a single language declaration.

Page 1 is English and page 2 is Spanish, but the file declared en-US for everything. 66 Spanish elements are now marked es and 50 English elements en-US; the document-level language is Spanish because it carries the larger share of the text.

Twenty-five links with no description.

Every link annotation lacked a Contents entry, so assistive technology announced them with no name. Each now carries the visible link text, or the destination URL where the link sits on no text.

Untagged rules and borders.

Sixteen path-painting operators (table rules and dividers) were outside any tag. They were marked as artifacts. No text was outside the tag tree.

Rendering

All 2 pages render pixel-identical to the published file at 100 dpi. Nothing visible changed.

Not covered by this pass

  • Reading order was not re-sequenced. The existing tag order was kept.
  • Alternate text was not written or rewritten. Existing alternate text was kept as published.
  • Table header scope was assigned by position (first row = column headers, leading cell = row header). A human check against the visual table is recommended for complex tables.
  • No content was translated, corrected or rewritten. Where the published file contains untranslated or outlined text, this report says so; fixing it needs the issuer's source.
  • Form-field tooltips (Designer forms) were kept as published; their language and wording were not reviewed.
