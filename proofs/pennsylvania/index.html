Proof of work · Pennsylvania public documents

The form a nurse with a disability uses to request a testing accommodation failed nine accessibility rules. It now fails none.

Thirteen documents published by the Pennsylvania Office of Administration, the Pennsylvania Department of Health, the Pennsylvania State Board of Nursing, and the Erie County Department of Health, downloaded from the agencies' own pages and measured with veraPDF against PDF/UA-1 (ISO 14289-1). Each was repaired, measured again, and compared against the original page by page - by raster where the fix was structural, and word by word where a font had to be embedded. Six now pass with zero failed rules, including the Board’s own Request Form for Testing Accommodations and the Commonwealth’s own Digital Accessibility Policy. The other seven are published here with exactly what remains and why, because that gap is the honest part of this work.

These six carry the PDF/UA-1 identifier because veraPDF independently passed them first, 106 rules out of 106. The identifier is written by hand at sign-off, never by the tool, and never before the file has earned it.

Pennsylvania Office of Administration

Digital Accessibility Policy (effective November 12, 2025)

Before FAIL 6 rulesAfter PASS 0 / 106Rendering 4/4 pixel-identical

This is the policy that sets WCAG 2.1 Level AA as the standard for every Commonwealth agency, and it was six rules short of PDF/UA-1 itself. In fairness it was the closest file on this page: tagged, marked, titled, declared as English, with real alternative text already written for the Office’s logo. Somebody did that work. What remained was small — six links with no accessible name, one horizontal rule four points wide tagged as a picture, four empty spaces left unmarked, and one font carrying a stale character set. Nothing about what the document says changed, and all four pages render identically.

Pennsylvania Department of Health

Medical Certificate · School Immunization Card

Before FAIL 5 rulesAfter PASS 0 / 106Text 204/204 words unmoved

Untagged and unmarked on arrival, with three fonts named but not carried. Tagged, then the same three typefaces embedded from the names the file already used.

Conforming PDF

About the fonts, because it is the one claim on this page that needs a caveat. The accommodations form names Arial and Times New Roman but does not carry them, so what a reader sees today depends on which fonts that reader’s machine happens to have. That is the defect the rule exists to prevent. The remediated file embeds the same typefaces the document already names, subset to the glyphs actually drawn, after checking each font’s own embedding-permission bits. Every one of the 397 words sits in the same place to within half a point; what changes is that the letterforms are now fixed rather than guessed. The same was done for the Medical Certificate and the School Dental Form. The other three conforming files needed no font work and are byte-for-byte pixel-identical, including all twenty-six pages of the Professional Nursing Law.

What is left is not a queue of easy wins. Four of the seven fail on table structure or on a scan. The other three are interactive forms whose fields carry no accessible name, so a screen reader announces the field but not what it asks for; naming those means reading each label off the page and deciding which field it belongs to. Deciding that a row’s last cell was merged across two columns, or re-typing a scan, changes what the document says. A script that decides those things produces a file that passes a validator and misreads to the person using a screen reader, which is worse than the honest failure. Those stay on this list until a person does them.
Every “after” count above still includes one rule that is failing on purpose. Clause 5 is the PDF/UA conformance identifier. This pipeline refuses to write it. A file gets that identifier only after a validator has independently passed everything else, which is why seven of these thirteen are published as failing rather than stamped and called done.

How to read these

  • Before / after are veraPDF 1.30.2 failed-rule counts on the published file and on the remediated file, same profile, same version.
  • Rendering is a 100 dpi raster comparison of every page. Both conforming files are pixel-identical to what the agency published.
  • What is still failing is the part that matters. Unembedded fonts need the agency's font licences. Alt text, heading rank, and table structure are meaning, not syntax, and a script that guesses at them produces a file that passes a validator and still fails a reader.
  • Source documents are Pennsylvania public records, reproduced here for a technical demonstration. They remain the property of their issuing agencies.
